# Aviso legal e de uso

Este site é um companheiro de mesa para consulta e organização privada.

Não contém:

- PDF original;
- artes do livro;
- páginas escaneadas;
- layout do livro;
- tradução integral;
- reprodução extensiva do texto original.

O conteúdo é um resumo/paráfrase para facilitar a mesa, com indicações de páginas para consulta no livro adquirido.
